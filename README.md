R2 is an embedded finance platform operating across Latin America (Mexico, Brazil, Chile, Colombia and Peru) that lets digital platforms and marketplaces offer revenue-based financing to their merchants. Through R2's REST APIs and embeddable JavaScript components, partners share merchant and transaction data for credit scoring, surface pre-approved offers, run KYC, disburse capital, and reconcile sales-based repayments via collections. R2 reports having facilitated over 180,000 loans and is backed by General Catalyst.

**Areas:** Company · Financial Services · Embedded Finance · Lending · Payments · Fintech · Latin America · Revenue-Based Financing · Webhook

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for R2: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
